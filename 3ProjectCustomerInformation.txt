Business Requirements:
	1- sort the data in the two tables.
	2- Join the data of the customers of into one table bases on the customer ID
	3- Filter the data on the state= 'KS'
	4- Find Count of customers where state = 'KS', for each area in the state
	5- Save the counts into a rational database 
________________________________________________________________________  

Extra:
	5- Find total customers with international Plan
	6- Find total customers without voice_mail_plan
	7- Find average for number_vmail_messages
________________________________________________________________________  

Steps:
1- create new project folder[Project_CustomersInformation]   
2- create new folder inside that project file[DirCustomersInformation]  
3- create new data object and get the source1 dataset flat file[SRC1_customer_feedback]  
4- Get the source2 dataset flat file[SRC2_full_customers]
5- Create a map [m_CustomersInformation] 
6- Import the two sources [[SRC1_customer_feedback],[SRC2_full_customers]] flat files into the map as read
7- check data types for each column and its lengths:
	source1 data type Conversion 
		customer_id: string(11)->string(11)
		feedback_text: string->string 
		feedback_category: string->string
		sentiment: string->string
		complaint_intensity:number->int    Note:This value repesent ordinal Qualitative (Categorical)
		
	source2 data type Conversion	
		customer_id: string(11)->string(11)
		state: string(2)->string(2)
		account_length: number->string(10)
		area_code: number->string(3)
		international_plan: string(3)->string(3)
		voice_mail_plan: string(3)->string(3)
		number_vmail_messages: number->int(10)

8- use sorter transformataion[SRT1_CT] --Note CT: CustomersTransformation 
9- use sorter transformataion[SRT2_CT] D

10- In sorter transforamtion[SRT1_CT] properties Tab: 
		ports: check data type and their length according to the column data type conversion used in step 5
 		sort: choose (customer_id) for ascending order

11- In sorter transforamtion[SRT2_CT] properties Tab:D
		ports: check data type and their length according to the column data type conversion used in step 5
 		sort: choose (customer_id) for ascending order

12- Create the joiner[JN_CT] between the two sorter: 
	in the properties tab of the joiner
		grneral: [Name:JN_CT]
		join: [join type:Normal]
			  join condition: [customer_id1=customer_id]
		Advanced:[sorted_input checked]
		
13- Create the filter transformation [FIL_CT]:
	use all the ports as input for the filter transformation
    use [state='KS'] as filter condition                                
					
14- Create the aggregator[AGG_CT]:
	use all the ports as input for the filter transformation
	create a new port [CNT_CUSOMERS] with output only, and expression [COUNT(customer_id)]
	group by: area_code port
15- create a table [CustAgg] in relational database as follows:
	CREATE TABLE CustAgg(customerID VARCHAR(20), CNT_CUSOTMERS INT, AREA_CODE CHAR(3));
	
16- create a relational database connection in informatica developer with a database that contains that table[CustAgg] 
17- Insert the table[CustAgg] into the map as write in the map [m_CustomersInformation]
18- Run the map [m_CustomersInformation]
19- Check the output into the table CustAgg(customerID
